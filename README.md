# confl — транслятор учебного конфигурационного языка (вариант 26)

## 1. Общее описание

`confl` — инструмент командной строки, который преобразует текст на учебном конфигурационном языке в JSON.

- Входной текст читается **из файла**, путь к которому задаётся ключом `-i` / `--input`.
- Выходной JSON печатается **в стандартный вывод**.
- Синтаксические и семантические ошибки выявляются с выдачей сообщений (с номером строки и столбца) в стандартный
  поток ошибок; код возврата при ошибке — `1`.
- Синтаксический разбор выполняет специализированный инструмент — парсер-генератор
  [Lark](https://github.com/lark-parser/lark) (LALR(1)). Грамматика языка находится в `src/confl/grammar.py`.
- Язык реализации — Python 3.8+.

### Синтаксис языка

| Конструкция                   | Запись                                                 |
|-------------------------------|--------------------------------------------------------|
| Однострочный комментарий      | `" Это однострочный комментарий` (до конца строки)     |
| Многострочный комментарий     | `\|# ... #\|` (может занимать несколько строк)         |
| Число                         | `[0-9]+` (целое без знака, ведущие нули допустимы)     |
| Имя                           | `[_A-Z][_a-zA-Z0-9]*`                                  |
| Словарь                       | `table( имя => значение, имя => значение, ... )`       |
| Значение                      | число, словарь или константное выражение               |
| Объявление константы          | `def имя = значение;`                                  |
| Вычисление константы          | `[имя]`                                                |
| Константное выражение         | постфиксная форма в квадратных скобках: `[имя 1 +]`    |

Операции и функции константных выражений:

| Запись          | Операция             | Операнды | Пример                         |
|-----------------|----------------------|----------|--------------------------------|
| `+`             | сложение             | 2        | `[1 2 +]` → `3`                |
| `pow()`         | возведение в степень | 2        | `[2 3 pow()]` → `8` (`2^3`)    |
| `sqrt()`        | квадратный корень    | 1        | `[16 sqrt()]` → `4`            |

Результатом вычисления константного выражения является значение, поэтому `[...]` можно использовать везде, где
допускается значение: в правой части `def`, в словаре и на верхнем уровне.

### Принятые уточнения к заданию

Там, где задание допускает несколько прочтений, выбрано следующее:

1. **Структура файла**: любое число объявлений `def` и затем ровно одно корневое значение (обычно словарь `table(...)`).
   Именно корневое значение попадает в JSON. Файл без корневого значения — синтаксическая ошибка.
2. **Порядок констант**: константа может использовать только константы, объявленные выше. Повторное объявление
   константы — ошибка. Ссылка на себя — ошибка (константа ещё не определена).
3. **Постфиксная запись**: `a b pow` вычисляет `a` в степени `b`. Функции допустимо писать как `pow()`, `sqrt()`
   (форма из задания) и как `pow`, `sqrt`.
4. **Словари**: допускаются пустой словарь `table()` и необязательная запятая после последней пары. Повторяющийся
   ключ — ошибка. Порядок ключей в JSON сохраняется.
5. **Типы в выражениях**: операции принимают только числа. Константу-словарь можно подставить через `[имя]`, но
   нельзя использовать как операнд `+`, `pow()`, `sqrt()`.
6. **Результат `sqrt()`**: целое число, если корень извлекается нацело (`[16 sqrt]` → `4`), иначе вещественное.
7. Выражение должно оставлять на стеке ровно одно значение.

## 2. Описание всех функций и настроек

### Настройки (ключи командной строки)

| Ключ              | Обязательный | Описание                                              |
|-------------------|--------------|-------------------------------------------------------|
| `-i`, `--input`   | да           | путь к файлу (UTF-8) с конфигурацией                   |
| `--version`       | нет          | вывести версию программы                              |
| `-h`, `--help`    | нет          | вывести справку                                       |

Коды возврата: `0` — успех; `1` — синтаксическая или семантическая ошибка, либо файл не удалось прочитать;
`2` — неверные аргументы командной строки (стандартное поведение `argparse`).

### Модули и функции

**`src/confl/cli.py`** — интерфейс командной строки

- `build_parser()` — создаёт разборщик аргументов командной строки.
- `read_source(path)` — читает текст конфигурации из UTF-8 файла.
- `report(path, message)` — печатает ошибку в `stderr` и возвращает код `EXIT_FAILURE`.
- `main(argv=None)` — точка входа: читает файл, транслирует, печатает JSON, возвращает код возврата.

**`src/confl/converter.py`** — трансляция в JSON

- `translate(text)` — разбор и вычисление; возвращает число или `dict`.
- `to_json(data)` — сериализация в JSON с отступом в 2 пробела (запрещены `NaN` и бесконечность).
- `convert(text)` — `translate` + `to_json`.

**`src/confl/parser.py`** — синтаксический разбор (Lark)

- `parse(text)` — возвращает синтаксическое дерево или выбрасывает `ConfigSyntaxError`.
- `describe(error)`, `describe_unexpected_char(error)`, `describe_unexpected_token(error)` — формируют текст
  сообщения об ошибке разбора, включая список допустимых в этом месте токенов.
- `display_name(terminal)` — читаемое имя терминала грамматики.
- `known_position(value)` — нормализует номер строки или столбца.

**`src/confl/evaluator.py`** — вычисление дерева

- `Evaluator.evaluate(tree)` — обрабатывает объявления и возвращает значение корня.
- Методы `Evaluator`: `_define` (объявление константы), `_value`, `_number`, `_dict`, `_const_expr`
  (постфиксное выражение на стеке), `_step`, `_lookup` (поиск константы).
- `apply_operator(token, stack)` — применяет операцию к вершине стека.
- `check_numbers(operands, token)` — проверяет, что операнды — числа.
- `compute(function, operands, token)` — вызывает операцию, превращая арифметические сбои в ошибки.
- `power(base, exponent)`, `square_root(value)` — функции `pow()` и `sqrt()`.
- `error_at(message, token)` — создаёт `ConfigSemanticError` с позицией токена.

**`src/confl/errors.py`** — ошибки

- `ConfigError` — базовый класс (сообщение, строка, столбец).
- `ConfigSyntaxError` — нарушение грамматики. `ConfigSemanticError` — ошибка вычисления.

### Сообщения об ошибках

```
confl: config.confl: syntax error at line 3, column 3: unexpected name 'B'; expected: ')', ','
confl: config.confl: error at line 2, column 9: undefined constant 'X'
```

## 3. Сборка проекта и запуск тестов

Сборки как таковой нет, достаточно установить зависимости (нужен Python 3.8+). В современных Linux-дистрибутивах
системный `pip` заблокирован (PEP 668), поэтому используйте виртуальное окружение:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt    # или: make install
```

Запуск тестов:

```sh
python3 -m pytest                  # или: make test
```

Тесты покрывают все конструкции языка с учётом вложенности (комментарии обоих видов, числа, словари, объявления и
вычисления констант, все операции), все виды ошибок, интерфейс командной строки и оба примера из `examples/`.

## 4. Примеры использования

Запуск (любой из вариантов):

```sh
./run.sh -i examples/cluster.confl
python3 -m confl -i examples/cluster.confl     # при PYTHONPATH=src
make run FILE=examples/cluster.confl
```

### Пример 1: кластер веб-сервисов (DevOps) — `examples/cluster.confl`

```
" Конфигурация кластера веб-сервисов (предметная область: DevOps)
|#
Порты и размеры пулов вычисляются на этапе трансляции
из нескольких базовых констант.
#|
def BasePort = 8000;
def Replicas = 3;
def Workers = [Replicas 2 +];
def PoolSize = [Workers 2 pow];
def Timeouts = table(
  Connect => 5,
  Read => 30,
);

table(
  Cluster => table(
    Replicas => [Replicas],
    Workers => [Workers],
  ),
  Http => table(
    Port => [BasePort 80 +],
    AdminPort => [BasePort 1 +],
    Pool => [PoolSize],
  ),
  Timeouts => [Timeouts],
)
```

Результат:

```json
{
  "Cluster": {
    "Replicas": 3,
    "Workers": 5
  },
  "Http": {
    "Port": 8080,
    "AdminPort": 8001,
    "Pool": 25
  },
  "Timeouts": {
    "Connect": 5,
    "Read": 30
  }
}
```

### Пример 2: геометрия участка (землеустройство) — `examples/geometry.confl`

```
" Параметры участка (предметная область: землеустройство)
|#
Катеты прямоугольного треугольника заданы константами.
Гипотенуза и периметр вычисляются по теореме Пифагора.
#|
def LegA = 3;
def LegB = 4;
def Hypotenuse = [LegA 2 pow LegB 2 pow + sqrt];
def Side = 12;

table(
  Triangle => table(
    LegA => [LegA],
    LegB => [LegB],
    Hypotenuse => [Hypotenuse],
    Perimeter => [LegA LegB + Hypotenuse +],
  ),
  Square => table(
    Side => [Side],
    Area => [Side 2 pow],
    Diagonal => [Side 2 pow Side 2 pow + sqrt],
  ),
)
```

Результат:

```json
{
  "Triangle": {
    "LegA": 3,
    "LegB": 4,
    "Hypotenuse": 5,
    "Perimeter": 12
  },
  "Square": {
    "Side": 12,
    "Area": 144,
    "Diagonal": 16.97056274847714
  }
}
```
